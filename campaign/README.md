# GAIN 2026 campaign calendar

Internal page with the post copy and videos for the GAIN 2026 LinkedIn campaign.
Once this folder is in the repository, it is published at https://mitrovif.github.io/GAIN-story/campaign/

| Path | What it is |
|---|---|
| `index.html` | The calendar: timeline, list and Videos views. |
| `videos/` | The exported MP4s (add them, see below). Until a file is there, its player shows a mock-up. |
| `live/` | The live HTML versions of each film, with the runtime and assets they need. |

## Note on access

GitHub Pages sites are public, even when the link is only shared internally. If the films must stay private before launch, keep them in SharePoint instead and share that link.
