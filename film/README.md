# GAIN 2026 film

58-second flat isometric promo film for the GAIN 2026 survey, on the EGRISS Design System
(navy / teal palette, Obvia headings, IBM Plex Sans captions, the official EGRISS logo),
with an original score and a voiceover.

| File | What it is |
|---|---|
| `GAIN2026_film_1920x1080.mp4` | Landscape master, 30 fps, captions burned in, stereo AAC soundtrack |
| `GAIN2026_film_1080x1350.mp4` | 4:5 cut, reframed for feeds |
| `src/config.js` | All on-screen words: captions, map labels, title, deadline, landing URL |
| `src/film.js` | The animation (canvas, deterministic per frame) |
| `vo.py` | The voiceover script and timing; writes `vo.wav` (guide voice: macOS Samantha, or your recordings with `--recorded`) |
| `src/covers/` | Real report covers from `assets/covers-web`, as shown for those examples on the launch page |
| `music.py` | The score and sound design, written to the film's timeline; writes `mix_raw.wav` and `src/env.json` |
| `render.js`, `mux.sh` | Render both formats with headless Chrome + ffmpeg and add the soundtrack |
| `audit.js` | Checks every on-screen text reaches 24px (`node audit.js 1920 1080`) |

## Music

Original, generated by `music.py`: D major, 100 BPM, felt piano, pad, plucked arpeggio, soft kick
and shaker. Downbeats fall every 2.4 s from 0.8 s; scene cuts, the dot leaving the laptop (17.6 s),
its arrival at each scene and the map labels sit on that grid. Sound effects are CC0: door knocks
and clicks from Kenney.nl, key taps from the unicae_games keyboard pack. No licensing restrictions.

## Voiceover

The captions are spoken, each line placed on its caption's cue; the music ducks under the voice.
The current voice is a guide track from macOS (`say -v Samantha`). For the final film, record one
file per line (13 lines, listed in `vo.py`) as `vo/line_00.wav` … `vo/line_12.wav` and run
`./mux.sh --recorded`.

## Change the text and re-render

Edit `src/config.js` (for example replace `[landing page URL]`), then:

```bash
cd film && npm i puppeteer-core@22.15.0
./mux.sh
```

The render takes about 10 minutes. Preview stills: `node render.js 1920 1080 stills --stills 5,25,53`.
