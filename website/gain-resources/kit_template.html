GAIN Resources page update

Glossary and FAQ in English, French, Spanish, Russian and Arabic. Built __BUILT__.

This file holds everything needed to update the GAIN Resources page on egrisstats.org. It adds a language switch to the Glossary and FAQ sections. English stays the default.

1. Upload the FAQ PDFs

In WordPress, go to Media › Add New and upload the four translated FAQ PDFs with exactly these file names:

__PDF_ROWS__
LanguageFile name

Question 15 of the translated PDFs contains the shared login for viewing submissions. Remove it first if it should not be public.

2. Replace the page code

  1. Copy the code with the button below, or download it as a file.
  2. Open the page in WordPress and choose Edit with the Divi builder.
  3. Open the full-width Code module that holds the questionnaires, glossary and FAQ (the only code module on the page).
  4. Select all of its content, delete it, and paste the new code.
  5. Save the module, then Save the page.
  6. Open the links in step 3 to check each language.

3. Links for emails

Each link opens the page at that section, in that language.
